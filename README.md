# ResearchPath Guide

ResearchPath Guide is a structured, step-by-step research workflow guide built to help trainees move from idea → protocol → search strategy → screening → data extraction → synthesis → writing.  
This repo contains an MVP web app for organizing those steps and templates in a single place.

## What it does (MVP)
- Provides a **modular research workflow** (topic selection, PICO, protocol, PRISMA, analysis)
- Includes **templates/checklists** for common research tasks
- Designed for rapid iteration based on user feedback (students / early-career researchers)

- Core layout + content scaffolding: ✅
